Задание #546

Baby XDP

Куда же делись мои сетевые пакеты?

В этом задании мы предлагаем вам поиграть с XDP.

Злоумышленник настроил скрытый канал связи между зараженной машиной и сетью. Сможете ли вы восстановить содержимое пакетов, полученных на сетевом интерфейсе? tcpdump, похоже, не работает…

Примечания:

- Чтобы получить работающий Ctrl-c, вы можете использовать stty -cooked -echo в своем терминале после отправки соединения с заданием, установленного с помощью nc, в фоновый режим. - Чтобы воспроизвести задание локально: Распакуйте архив с помощью tar xf babyxdp.tar.xz. Запустите Docker-контейнер с помощью docker compose up --build. Подключитесь к локальному заданию с помощью nc localhost 4000. - Для входа на машину используйте пароль «user»
