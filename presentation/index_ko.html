챌린지 #546

Baby XDP

내 네트워크 패킷들은 다 어디로 갔을까요?

이번 문제에서는 XDP를 다뤄보는 것을 제안합니다.

공격자가 감염된 머신과 네트워크 사이에 은밀한 통신 채널을 구축했습니다. 네트워크 인터페이스에서 수신된 패킷의 내용을 찾아낼 수 있을까요? tcpdump가 작동하지 않는 것 같습니다…

참고 사항:

- 정상 작동하는 Ctrl-c를 사용하려면, nc로 연결한 챌린지를 백그라운드로 전환한 후 터미널에서 stty -cooked -echo를 사용할 수 있습니다. - 로컬에서 문제를 재현하려면: tar xf babyxdp.tar.xz로 압축을 해제합니다. docker compose up --build로 Docker 컨테이너를 실행합니다. nc localhost 4000으로 로컬 챌린지에 접속합니다. - 머신에 접속하려면 비밀번호 "user"를 사용하세요.

분석할 파일:

../files/babyxdp.tar.xz
